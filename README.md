# 🩺 Breast Cancer Detection using Deep Learning

## 📌 Overview
This project is a web application that detects whether a breast tissue image is **Benign** or **Malignant** using a Deep Learning model. The application is built with **Python, Flask, and TensorFlow** and provides an easy-to-use interface for image classification.

## ✨ Features
- Upload breast tissue images
- Predict Benign or Malignant
- Display prediction confidence
- Simple and user-friendly interface
- Flask-based web application

## 🛠️ Technologies Used
- Python
- Flask
- TensorFlow / Keras
- HTML
- CSS
- Bootstrap

## 📂 Dataset
- **BreakHis (Breast Cancer Histopathological Database)**

## 🚀 How to Run
1. Clone the repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run:
   ```
   python app.py
   ```
4. Open:
   ```
   http://127.0.0.1:5000
   ```
